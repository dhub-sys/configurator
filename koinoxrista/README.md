# Κοινόχρηστα — Joomla 6 SaaS

SaaS για διαχειριστικές εταιρείες και επαγγελματίες διαχειριστές πολυκατοικιών: κτίρια, ιδιοκτησίες,
χιλιοστά, δαπάνες, θέρμανση, έκδοση κοινοχρήστων, εισπράξεις και **εκτύπωση σε προτυπωμένα έντυπα A4**.
Η πλατφόρμα έχει δικά της **πακέτα χρεώσεων**, που τα ορίζει ο ιδιοκτήτης της.

Ίδια αρχιτεκτονική με το Dashboard (com_supportplans): Joomla 6 component, standalone οθόνη χωρίς το
template του site (`tmpl=component`), δική του σύνδεση πάνω στους χρήστες του Joomla, white label.

## Εγκατάσταση

```bash
./tools/build.sh            # → dist/com_koinoxrista-1.0.0.zip
```

Joomla Administrator → System → Install → Extensions → ανέβασμα του zip.
Η εφαρμογή ανοίγει από το μενού «Κοινόχρηστα» του administrator ή απευθείας:

```
https://example.gr/index.php?option=com_koinoxrista&view=app&tmpl=component
```

Οι Super Users του Joomla μπαίνουν ως **διαχειριστές πλατφόρμας**. Οι πελάτες κάνουν εγγραφή από την
οθόνη σύνδεσης (ή τους δημιουργείτε εσείς από Πλατφόρμα → Συνδρομητές). Η εγκατάσταση δημιουργεί
4 ενδεικτικά πακέτα και 2 πρότυπα εκτύπωσης. Μια αναβάθμιση δεν αλλάζει όσα έχετε ορίσει.

## Ρόλοι

| Ρόλος | Τι κάνει |
|---|---|
| Διαχειριστής πλατφόρμας (Joomla Super User) | Πακέτα χρεώσεων, συνδρομητές, πληρωμές συνδρομών, ρυθμίσεις & white label, πρότυπα συστήματος, «Είσοδος» σε λογαριασμό πελάτη για υποστήριξη |
| Υπεύθυνος λογαριασμού (owner) | Ό,τι αφορά τα κτίρια του, στοιχεία εταιρείας, χρήστες, αίτημα πακέτου |
| Συνεργάτης (staff) | Κτίρια, μήνες, δαπάνες, εισπράξεις, εκτυπώσεις |
| Ένοικος / ιδιοκτήτης | Χωρίς λογαριασμό: βλέπει το ειδοποιητήριό του από υπογεγραμμένο σύνδεσμο στο email |

## Λειτουργίες

**Κτίριο**: ονομασία, πλήρης διεύθυνση, ΑΦΜ, IBAN/τράπεζα/δικαιούχος, στοιχεία διαχειριστή (τηλέφωνα,
email, διεύθυνση, ώρες), εκπρόσωπος κτιρίου, θέρμανση (είδος, τρόπος κατανομής, πάγιο %, μονάδα καυσίμου),
προθεσμία πληρωμής. Αρχειοθέτηση ή οριστική διαγραφή.

**Ιδιοκτησίες & χιλιοστά**: επεξεργασία σαν λογιστικό φύλλο (κωδικός, όροφος, είδος, τ.μ., ιδιοκτήτης,
ένοικος, επικοινωνία, ποιος πληρώνει, συντελεστής θέρμανσης, υπόλοιπο έναρξης). Στήλες χιλιοστών
γενικών / ανελκυστήρα / θέρμανσης και όσες πρόσθετες χρειάζεστε. Ζωντανός έλεγχος συνόλων (1000).
Επικόλληση από Excel.

**Μήνας**: δαπάνες με κατηγορία (= στήλη εκτύπωσης), τρόπο κατανομής (χιλιοστά, ισόποσα, τ.μ., θέρμανση
πάγιο + κατανάλωση, μόνο κατανάλωση, συγκεκριμένα ποσά), βαρύνει ένοικο ή ιδιοκτήτη, υποσύνολο
ιδιοκτησιών, προμηθευτής/παραστατικό, επαναλαμβανόμενες δαπάνες που περνούν στον επόμενο μήνα.
- **Θέρμανση**: υπολογισμός καυσίμου (αρχικό + αγορές − τελικό, σταθμισμένη τιμή) → δαπάνη με ένα κλικ.
  Ενδείξεις ωρομετρητών/θερμιδομετρητών με αυτόματη μεταφορά των προηγούμενων ενδείξεων.
- **Κατανομή**: κάθε δαπάνη μοιράζεται σε λεπτά με τη μέθοδο του μεγαλύτερου υπολοίπου, ώστε το σύνολο
  να βγαίνει πάντα ακριβώς ίσο με το ποσό της δαπάνης.
- **Έκδοση**: κλειδώνει τον μήνα, «παγώνει» τα ποσά (snapshot) και χρεώνει τις ιδιοκτησίες. Ο επόμενος
  μήνας δείχνει το προηγούμενο υπόλοιπο (έναρξη + εκδοθέντες μήνες − εισπράξεις έως την ημερομηνία έκδοσης).
  Αναίρεση έκδοσης μόνο για τον τελευταίο εκδοθέντα μήνα.
- Εξαγωγή σε Excel (CSV) και αποστολή ειδοποιητηρίων με email.

**Εισπράξεις**: υπόλοιπο ανά ιδιοκτησία, καρτέλα κινήσεων, είσπραξη με αύξουσα αρίθμηση ανά κτίριο,
απόδειξη A4 (στέλεχος + αντίτυπο), φίλτρο οφειλετών.

## Εκτύπωση σε προτυπωμένα έντυπα

Κάθε πρότυπο είναι μια λίστα στοιχείων σε **χιλιοστά του χαρτιού** (`field`, `text`, `table`, `line`, `box`,
`image`). Κάθε στοιχείο ανήκει σε επίπεδο:

- **Έντυπο**: ό,τι είναι ήδη τυπωμένο στο χαρτί (τίτλοι, γραμμές, επικεφαλίδες πινάκων)
- **Δεδομένα**: τα στοιχεία του μήνα

Τρόποι εκτύπωσης: **λευκό χαρτί** (όλα), **προτυπωμένο** (μόνο δεδομένα), **κενό έντυπο** (μόνο το έντυπο:
τυπώνετε τα δικά σας «προτυπωμένα»). Τύποι: κατάσταση κοινοχρήστων (πίνακας κτιρίου, συνεχίζει σε νέα σελίδα
όταν δεν χωρούν οι ιδιοκτησίες) και ειδοποιητήρια (1–4 ανά A4).

Ταίριασμα σε αγορασμένο έντυπο:
1. Πρότυπα εκτύπωσης → Αντίγραφο.
2. Στον σχεδιαστή ανεβάζετε σάρωση του κενού εντύπου ως φόντο (φαίνεται μόνο στην οθόνη).
3. Σύρετε τα πεδία στις θέσεις τους (βελάκια: 0,5 mm, Shift: 5 mm, Alt: 0,1 mm).
4. Δοκιμαστική εκτύπωση με «Πλέγμα» σε λευκό χαρτί, σύγκριση κόντρα στο φως, και διόρθωση μετατόπισης:
   μόνιμα ανά εκτυπωτή (Λογαριασμός → Εκτύπωση), ανά πρότυπο, ή για μία εκτύπωση από τη γραμμή εργαλείων.

Στο παράθυρο εκτύπωσης του browser: **Περιθώρια: Κανένα**, **Κλίμακα: 100%**, χωρίς κεφαλίδες/υποσέλιδα.

## Πακέτα χρεώσεων

Πλατφόρμα → Πακέτα χρεώσεων: τιμή μήνα/έτους (προ ΦΠΑ), όρια (κτίρια, ιδιοκτησίες, χρήστες, 0 = απεριόριστα),
ημέρες δοκιμής και λειτουργίες: σχεδιαστής προτύπων, θέρμανση με μετρητές, email ειδοποιητήρια,
εισπράξεις, εξαγωγή Excel.

Ροή: εγγραφή → δοκιμαστική περίοδος → ο πελάτης επιλέγει πακέτο (αίτημα + email σε εσάς) → πληρώνει με
τον τρόπο που ορίζετε στις ρυθμίσεις → εσείς καταχωρίζετε την πληρωμή (Πλατφόρμα → Συνδρομητής) και η
συνδρομή παρατείνεται αυτόματα. Όταν λήξει, ο λογαριασμός γίνεται μόνο για ανάγνωση και εκτύπωση.

## Δομή κώδικα

```
koinoxrista.xml, script.php                 manifest, αρχικά πακέτα & πρότυπα
administrator/components/com_koinoxrista/   service provider, SQL, launcher
components/com_koinoxrista/src/
  Dispatcher/Dispatcher.php                 πύλη σύνδεσης (δημόσιες μόνο login/εγγραφή/ειδοποιητήριο)
  Controller/*                              ενέργειες (POST + CSRF token)
  Helper/Calc.php                           μηχανισμός κατανομής (καθαρή PHP, tests)
  Helper/Render.php, Layouts.php            εκτύπωση A4 σε mm, έτοιμα πρότυπα, κατάλογος πεδίων
  Helper/Repo.php                           δεδομένα με έλεγχο ότι ανήκουν στον λογαριασμό
  Helper/Auth.php                           σύνδεση, ρόλοι, πακέτο, όρια, κατάσταση συνδρομής
components/com_koinoxrista/tmpl/*           οθόνες
media/css, media/js                         app.css, print.css, app.js, designer.js
tests/                                      calc_test.php, render_preview.php, e2e.js
```

## Δοκιμές

```bash
php tests/calc_test.php                       # κατανομή, στρογγυλοποίηση, θέρμανση, καύσιμο
php tests/render_preview.php /tmp/out         # HTML προεπισκοπήσεις των έτοιμων προτύπων
node tests/e2e.js http://localhost:8080 /tmp/shots   # όλη η ροή σε εγκατεστημένο Joomla 6
```

## Επόμενα βήματα (προτάσεις)

- Online πληρωμή συνδρομής (Stripe / Viva Wallet) και αυτόματη έκδοση τιμολογίου.
- Κωδικός πληρωμής RF / QR στο ειδοποιητήριο και συμφωνία κινήσεων τράπεζας (import CSV).
- Portal ενοίκων με ιστορικό ειδοποιητηρίων και αποδείξεων.
- Ταμείο κτιρίου / αποθεματικό με κινήσεις και ετήσια απολογιστική κατάσταση.
- Υπενθυμίσεις οφειλών με email/SMS μέσω Joomla Scheduled Tasks.
- Εισαγωγή από άλλα προγράμματα κοινοχρήστων.
